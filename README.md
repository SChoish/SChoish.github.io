# Soohyun Choi — Academic Website

Static source for `https://schoish.github.io/`.

The site is intentionally lightweight and uses plain HTML and CSS so that it can be served directly by GitHub Pages without a build step.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Updating the CV

Replace `assets/Soohyun_Choi_CV.pdf` with the latest PDF while keeping the filename unchanged.
